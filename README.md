# GitHub User Activity CLI

A simple CLI application written in C# that fetches and displays recent GitHub activity for a given user.

Project URL: https://github.com/tarikc21/github-user-activity

## Features

- Fetches recent public GitHub events for a user
- Displays events in a readable format
- Supports multiple event types (PushEvent, WatchEvent, IssuesEvent, etc.)
- Uses GitHub REST API

## Usage

Run the program with a GitHub username:

```bash
dotnet run <username>
